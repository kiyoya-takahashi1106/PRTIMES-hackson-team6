# 解く課題

このプロジェクトでは、PR TIMES 利用者のつまずきを大きく2つに整理しています。

## 1. 初回利用者が自力で進めにくい

初めて使う担当者は、原稿作成、配信設定、メディアリスト選定、配信後の確認までの流れを把握しづらい。
その結果、営業担当者や社内の経験者に都度確認が必要になり、配信までに時間がかかります。

### 対象ユーザー

- PR TIMES を初めて使う広報担当者
- 広報経験が浅い担当者
- 前任者から業務を引き継いだ担当者
- 社内に相談できる人がいない担当者

### 提供したい価値

利用段階に応じた案内を出し、初回利用者でも配信から振り返りまで迷わず進められる状態にします。

## 2. 配信しても成果につなげにくい

ユーザーは「掲載されたい」「認知を広げたい」という期待を持っています。
一方で、その期待に合う原稿内容やメディアリストを設計できず、配信後の結果も次回改善に活かしづらい状態です。

### 主な原因

- 何をニュースとして打ち出すべきか判断しづらい
- タイトルや切り口の良し悪しを判断しづらい
- 約2万件のメディアから適切な配信先を選びづらい
- 配信結果の良し悪しや原因が分かりづらい
- 次回、内容とメディアリストのどちらを改善すべきか分かりづらい

### 対象ユーザー

- 1回以上配信したが、期待した成果が出ていないユーザー
- 成果につながる原稿やメディアリストの作り方が分からないユーザー
- 配信結果を見ても次の改善行動に落とし込めないユーザー

### 提供したい価値

成果につながる「原稿内容」と「メディアリスト」の設計を支援し、配信後の結果を次回改善につなげられる状態にします。
