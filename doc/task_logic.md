# PR TIMESにおける大きく2つの課題整理


# 課題①：使い方が分からず、ユーザーが自力で活用できない or PDCAサイクルが回せてない
## 理想状態
初めてPR TIMESを利用する担当者でも、発信のきっかけ整理、原稿作成、配信設定、メディアリスト選定、配信後の結果確認・次配信まで、一連の流れを理解して自力で進められる状態。

## 現状
〇〇
そのため、分からないことが発生するたびに、営業担当者や社内の経験者へ確認する必要がある。
営業担当者が、約30分の商談のうち約10分を、操作方法や基本的な使い方の説明に費やしているケースもある。

## GAP（問題）




## 真の課題特定・打ち手


## ターゲット
- PR TIMESを初めて利用する広報担当者
- 広報業務やプレスリリース配信の経験が浅い担当者
- 前任者からPR業務を引き継いだ担当者
- 社内に使い方を教えられる人がいない担当者
- 基本操作について営業担当者へ繰り返し問い合わせている担当者

## 誰に何を届けたいか
PR TIMESの利用方法に不安を抱える担当者に対して、利用段階に応じた案内を届け、初回利用者や後任者でも、配信から振り返りまでを迷わず自力で進められる状態を提供する。

## 解決することで起こる良い影響
### 顧客への影響
- 初めて利用する担当者でも、一連の操作を自力で進められるようになる
- 操作方法や機能を調べる時間が減り、配信までの時間を短縮できる
- 担当者が変わっても、引き継ぎや再学習にかかる負担を減らせる
- PR TIMESを利用する心理的なハードルが下がり、継続的に活用しやすくなる
### PR TIMESへの影響
- 営業担当者が操作説明に費やす時間を削減できる
- 商談時間を、顧客の課題整理や成果向上に向けた提案へ使える
- 基本操作に関する問い合わせやサポート対応を減らせる
- 初回利用や担当者変更時のつまずきを減らし、利用定着率や継続率の向上につなげられる

# 課題②：期待する効果を得られず、成果につながる配信を継続できない
## 理想状態
一度プレスリリースを配信したユーザーが、期待する効果を得られている状態。
また、一度の配信で期待する効果を十分に得られなかった場合でも、配信結果を振り返り、次回の配信を改善することで、期待する効果へ近づけられる状態を目指す。

## 現状
ユーザーは、「このようなメディアに掲載されたい」「認知を広げたい」など、期待する効果を持っている。
一方で、その効果を得るために必要なプレスリリースの内容やメディアリストを適切に設計できていない。
※ 非アクティブ層が62%程度！！

## GAP（問題）
ユーザーが期待している効果と、実際にPR TIMESを利用して得られている効果との間にギャップがある。
さらに、一度の配信で期待する効果を得られなかった場合にも、その結果を次の配信へ活かしてギャップを縮めることができていない。

## 真の課題特定・打ち手
期待する効果を得られていない原因は、大きく以下の2つに分けられる。
※ ヒアリングでは、①の方がマス層（①を出来てないから、②にすら至ってないというのはある）
### ① 1回の配信で、成果につながる配信設計ができていない
一度のプレスリリース配信で期待する効果を得るためには、
1. 成果につながるプレスリリースの内容を作る
2. 作成した内容に合ったメディアへ届ける
必要がある。
しかし、現在はこの2つを適切に行うことが難しい。
※ ヒアリング上では「メディアリスト：内容＝6：4程度」
#### 真の課題①-1：成果につながるプレスリリースの内容を作れていない
ユーザー自身で、メディアが「取り上げたい」と感じる内容へプレスリリースを仕上げることが難しい。
特に、
- 何をニュースとして打ち出すべきか
- どのようなタイトル・切り口にすべきか
- どの情報を強調すべきか
- メディアや生活者にとって魅力的な内容になっているか
などを判断することが難しい。
そのため、企業側では伝えたい情報があったとしても、メディアに取り上げてもらえる形まで変換できていない。

#### 真の課題①-2：作成した内容に合ったメディアリストを選べていない
プレスリリースを作成した後、その内容に興味を持つ可能性が高いメディアへ届ける必要がある。
しかし、ユーザー自身が最初から、「このメディアに届けたい」という具体的なメディア候補を持っているわけではない。
その状態で、約2万件存在するメディアの中から、自分のプレスリリースと親和性の高いメディアを探す必要がある。
さらに、既存の絞り込み機能を利用して100〜200件程度まで減らしたとしても、
- どのメディアが自社の内容と最も合っているのか
- どのメディアなら取り上げてくれる可能性が高いのか
- 候補の中から何を優先して選べばよいのか
を判断する基準がなく、最終的な配信先を選ぶことが難しい。

###  ② 配信結果・フィードバックを次回の配信へ活かせていない
一度の配信で期待する効果が出なかったとしても、結果を振り返って改善すれば、次回以降に成果を高めていくことができる。
しかし現在は、配信結果やフィードバックを、次回の具体的な改善行動へ変換できていない。
この課題は、大きく以下の2つに分けられる。
#### 真の課題②-1：配信結果の良し悪し・原因が分からない
配信結果を確認しても、
- 今回の結果は良かったのか、悪かったのか
- 期待していた効果に対してどの程度達成できたのか
- なぜ期待する効果を得られなかったのか
を判断できない。
数値自体を見ることができても、その数値をどう評価すればよいのかが分からない状態。

#### 真の課題②-2：結果が分かっても、次回何を改善すればよいか分からない
結果が良くなかったことを理解できても、
- 内容を変えるべきなのか
- メディアリストを変えるべきなのか
- 内容のどこを修正すればよいのか
- どのメディアを追加・削除すればよいのか
が分からない。
そのため、結果を理解することと、次の具体的な行動との間にギャップがある。

### ターゲット
一度以上PR TIMESでプレスリリースを配信したものの、期待する効果を十分に得られていないユーザー。
特に、
- 一度配信したものの期待する成果が出なかった
- 成果につながるプレスリリースの作り方が分からない
- どのメディアへ配信すればよいか分からない
- 配信結果を見ても良し悪しが分からない
- 前回の結果を次回どう改善すればよいか分からない
- 成果を感じられず、その後利用しなくなった
ユーザーを対象とする。

### 誰に何を届けたいか
一度以上プレスリリースを配信したものの期待する効果を得られていないユーザーに対して、成果につながる「内容・メディアリストの設計」と、配信後の「結果の理解・次回への改善」を支援し、配信を重ねながら期待する効果を得られる状態を届ける。

## 解決することで起こる良い影響
### 顧客への影響
- メディアに取り上げられる可能性が高まる
- 認知拡大など、期待する成果を得やすくなる
- 一度成果が出なかった場合でも、原因を理解できる
- 次回何を改善すればよいか分かる
- 配信経験を積み重ねながら、広報活動の精度を高められる
- 「次も配信してみよう」と思える
### PR TIMESへの影響
- 「配信しても効果がなかった」という理由による離脱を減らせる
- 非アクティブ層の再利用につなげられる
- 初回から2回目、2回目から3回目への配信率を高められる
- 1社あたりの配信回数を増やせる
- 継続利用率・LTVの向上につながる
- 顧客の成功事例を増やせる
